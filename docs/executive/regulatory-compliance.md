# Sovereignty & Regulatory Compliance

This document details the data sovereignty protocols and regulatory compliance frameworks governing the infrastructure and data processing workflows.

---

## 🏛️ Regulatory Compliance Framework

The deployment adheres strictly to Malaysian data privacy and security regulations:

1. **Personal Data Protection Act (PDPA) 2010 Section 129:**
   - Mandates cross-border data transfer controls and data residency standards within sovereign boundaries (e.g., AWS AP-Southeast-5 Malaysia Region).

2. **PDPA 2024 Amendments:**
   - Enforces mandatory Data Breach Notification (DBN) requirements.
   - Outlines specific duties and appointments for Data Protection Officers (DPO).

3. **2025 Cross-Border Personal Data Transfer (CBPDT) Guidelines:**
   - Standardizes contractual clauses, risk assessments, and encryption protocols for off-shore data replication or hybrid cloud interconnects.

- Zero-trust network segmentation blocking external access to backend datastores.
