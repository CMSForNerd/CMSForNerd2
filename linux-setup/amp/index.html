🐧 Linux Setup Guide: Laboratory Readiness

Ensuring Node.js 22+ & Astro 7.1 Compatibility on Debian, Ubuntu LTS & AlmaLinux

RFC 2119 REQUIRED: To complete the laboratory modules, your development environment MUST run Node.js 22.0 or higher to compile Astro 7.1.

📦 Option A: Debian & Ubuntu

Using the official NodeSource repository to install the latest LTS version of Node.js.

# Install dependencies sudo apt update && sudo apt install -y curl ca-certificates gnupg git # Add NodeSource GPG Key and Repo curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash - # Install Node.js sudo apt update && sudo apt install -y nodejs # Verify installations node -v && npm -v

📦 Option B: AlmaLinux (9+)

Using the official DNF module streams to enable Node.js 22 on Red Hat-based environments.

# Enable Node.js 22 stream sudo dnf module reset nodejs -y sudo dnf module enable nodejs:22 -y # Install Node.js, npm, and git sudo dnf install -y nodejs npm git # Verify installations node -v && npm -v

📂 Workspace Initialization

Initialize the repository and install project-level node modules:

# Clone the workspace and enter directory git clone https://github.com/CMSForNerd/CMSForNerd2.git cd CMSForNerd2

Install local dependencies

npm install —legacy-peer-deps

Start Astro 7.1 dev server

npm run dev

🎓 Linux Compliance Summary

  • MUST: Deliver all package updates and npm commands via secure channels.
  • REQUIRED: Run Node.js v22.0 or higher.
  • SHOULD: Leverage Visual Studio Code with official Astro language extension support.
